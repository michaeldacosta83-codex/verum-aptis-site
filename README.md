# Verum Aptis website

Responsive one-page marketing site based on the supplied Verum Aptis brand and business plan. Open `index.html` in a browser to view it.

## Enquiry form

The contact section sends form submissions to the Verum Aptis Zapier Catch Hook. It sends name, email, company, optional company website URL, enquiry, source, and submission timestamp as a form-encoded POST. No enquiry test submission has been sent while configuring the site.

The Gmail acknowledgement workflow is configured in Zapier and needs a real first enquiry to verify its field mappings before activation.

## Hosting

The site is published on GitHub Pages at `https://michaeldacosta83-codex.github.io/verum-aptis-site/`. The Google Fonts import uses Manrope and DM Sans with system font fallbacks.
