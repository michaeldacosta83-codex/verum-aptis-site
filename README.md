# Verum Aptis website

Responsive one-page marketing site based on the supplied Verum Aptis brand and business plan. Open `index.html` in a browser to view it.

## Enquiry form

The contact section embeds the Verum Aptis lead form built in Zapier Interfaces. Form submissions are stored in the Zapier Table `Verum Aptis Website Enquiries` with name, email, enquiry, company, received date, status, and follow-up notes. The form displays an on-page confirmation after submission.

The Gmail acknowledgement Zap is being configured separately in the Verum Aptis Zapier account. It sends a short acknowledgement to the visitor's submitted email address after a new table record is created.

## Hosting

This folder can be published as a static site on GitHub Pages. The free GitHub Pages service provides a `github.io` address. The Google Fonts import uses Manrope and DM Sans with system font fallbacks.
